# Security policy

## Supported versions

Security fixes are provided for the latest released minor version. Procora is currently
beta software; upgrading to the newest release is recommended.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
[security advisory form](https://github.com/mhdihso/procora/security/advisories/new)
and include affected versions, reproduction steps, impact, and any suggested fix.

Never include real database credentials or private data in a report. You should receive
an acknowledgment within seven days.
